## 🚀 วิธีการใช้งาน (Quick Start Guide)

### 1️⃣ แบบที่ 1: รันผ่าน Node.js (Full Standalone App)
เหมาะสำหรับเปิดใช้งานระบบเต็มรูปแบบบนเครื่องคอมพิวเตอร์แบบ Offline:

#### บน Windows:
1. ดับเบิ้ลคลิกไฟล์ `start.bat`
2. เปิดเว็บบราวเซอร์ (Chrome / Edge / Firefox) แล้วไปที่: **http://localhost:3000**

#### บน macOS / Linux:
1. เปิด Terminal แล้วพิมพ์: `bash start.sh`
2. เปิดเว็บบราวเซอร์แล้วไปที่: **http://localhost:3000**

---

### 2️⃣ แบบที่ 2: เปิดด้วยไฟล์ HTML เดี่ยว (Single File HTML)
ไม่ต้องติดตั้ง Node.js หรือโปรแกรมใดๆ!
1. ดับเบิ้ลคลิกไฟล์ `standalone.html` หรือ `ai-mentor-th-standalone.html`
2. ไฟล์จะเปิดขึ้นบนเว็บเบราว์เซอร์ทันที และพร้อมใช้งานแบบ 100% Offline!

## 🛠️ คุณสมบัติเด่น (Features)
- 📚 **บทเรียนปัญญาประดิษฐ์**: What is AI, Machine Learning, Generative AI & Prompt Engineering, AI Ethics
- 🧪 **ห้องทดลอง AI Sandbox**:
  - Offline Smart Chatbot (ผู้ช่วยตอบคำถามเกี่ยวกับ AI)
  - Prompt Evaluator (วิเคราะห์และประเมินคำสั่งสั่ง AI ตามหลัก 4S)
  - Sentiment Analyzer (ตรวจจับอารมณ์ข้อความ บวก ลบ เป็นกลาง)
- 🏆 **ควิซวัดความรู้ & เกียรติบัตร**: แบบทดสอบ 5 ข้อ พร้อมระบบสร้างใบประกาศนียบัตรแบบพิมพ์ได้ (Printable Certificate)
- 📖 **พจนานุกรม AI & ส่องอาชีพ**: ค้นหาคำศัพท์ และดูเงินเดือน/ทักษะอาชีพแห่งอนาคต
